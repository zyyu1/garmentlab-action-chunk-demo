# L1 place overhang：轨迹补偿还是最终目标偏移（第一步核实）

日期：2026-11-02
数据：本地已下载的 `day4-l1-xfold-yaw-aware-*` 结果目录（10 例 `L1_XFOLD_OVERHANG=0.02`、3 例 overhang 0 基础例、1 例零扰动对照）。全部离线重算，未启动仿真，未上传任何文件。
脚本：`day4-actionchunk-test/l1_overhang_mechanism_audit.py`（只读，输出 `overhang_mechanism.json`）。
坐标系与评价器：与 `l1_yaw_fold_geometry.fold_metrics_yaw` 相同的 pick 中心 cloth-local 帧 `q = R(yaw)^T (v - pick)`；宽度 0.2 m，`pick_index=210`，fold line 在 `q.x = 0.2`，静止半远端边缘在 `q.x ≈ 0.4`。

## 判据

要区分两件事：

- **轨迹补偿**：机器人实际到不了名义 place 目标，overhang 用来补那 2 cm 的到位缺口。
- **最终目标偏移**：place 末目标本身被改到 +2 cm，机器人在两种配置下都精确到位；差别来自最终目标与最终静置构型，不是运动过程中的欠达。

## 结论：**最终目标偏移（final-target offset）**，不是轨迹补偿

三条独立证据：

1. **到位精度**：`03_place` 时被抓取粒子（pick）的实测位置与 commanded place 目标之差，overhang 例为 −0.1…−2.3 mm、基础例为 −0.1…−1.4 mm。两种配置都精确到位，不存在需要补偿的 2 cm 欠达。2 cm 直接体现为 commanded 目标本身（local x 0.200 → 0.220）。

2. **折形本身没变**：把理想 20/20 折形（移动半片关于 fold line 反射）刚体拟合到实测 flap 上，残差在两种配置里一致（overhang 4.1–4.6 mm、基础 4.0–4.9 mm，p95 ≈ 8 mm）；变化的只有平移量 dx：基础 +4.0…+4.4 mm，overhang +21.1…+24.5 mm。也就是说，overhang 没有改变折叠动作或折形质量，只把同一个折形整体外移约 2 cm。

3. **差别发生在释放之后，且来自支撑条件**：
   - 基础例：`03_place` 时 flap 自由边行均值停在静止半远端边缘外侧约 1–2 mm、**悬空 19.5–20.2 mm**；释放后仍悬空 16.3–17.4 mm，沿折向内滑（4100 391 mm、4105 394 mm、4107 369 mm），随后失稳摊平（`06` crossed 0.00、z 全部落到桌面）。
   - overhang 例：`03_place` 时自由边已越过静止半远端边缘 18.8–23.0 mm、悬空 13.8–16.2 mm；释放瞬间自由边**落到桌面**（0.1–1.0 mm），并继续外滑 1.5–1.8 cm（pick 417.2–420.2 → 431.5–438.0 mm），之后稳定（04→06 变化 ≤0.013 IoU）。
   - 因此差异不是"多探出 2 cm 才够得着"，而是 flap 自由边从"悬在静止半边缘上方"变成"落在边缘外桌面"，多出一个真实支点。

## 最终构型（10 例 overhang，settle 后）

| 量 | 值 |
|---|---|
| pick 粒子 q.x | 432.9–437.7 mm（名义 400 mm） |
| flap 自由边行 q.x | 433.2–438.0 mm |
| flap 越出静止半远端边缘（行均值） | 36.6–40.2 mm（9 例 39.1–40.2，4108 为 36.6） |
| flap 越边（单顶点最大值口径） | 约 49–52 mm |
| flap 自由边距桌面 | 0.1 mm（落桌面） |
| 拱高（移动半片最高点 - 桌面） | 62.2–63.4 mm |
| 最终 IoU（代理） | 0.37–0.42 |

对照：零扰动控制例（seed 0，overhang 0）通过且 flap 自由边始终保持悬空 17.1 mm、拱高 63.4 mm、IoU 0.57。**这是重要限制：overhang 不是"唯一能保持的折法"**，它把 10 个随机 L1 初态收敛到同一个"自由边落在桌面"的稳定构型；不能把它写成修复了机器人能力缺陷。

## 对定稿口径的影响

- L1 应如实记为**独立过折目标**：commanded place 末目标 +2 cm，最终静置构型比名义 20/20 折形外移约 4 cm（行均值口径），且是拱形+自由边落桌面，不是平面对折。
- 文档里此前的"越边约 4.1 cm"与本次行均值口径一致（39.1–40.2 mm）；单顶点最大口径可达 5.1 cm，两种口径都要标明，不能混用。
- overhang 只作用于第 4 个（place）目标，45/90/135 三个弧目标不变；基础例与 overhang 例的折形拟合残差相同，支持"只改最终目标"这一表述。
