## 1. 冻结范围与适用任务

配置：[stage4-success-v1.json](day4-actionchunk-test/stage4-success-v1.json)。评价器：[stage4_success_v1.py](day4-actionchunk-test/stage4_success_v1.py)。LF规范化SHA256清单：[stage4-success-v1-files.json](day4-actionchunk-test/stage4-success-v1-files.json)。旧 `fold_metrics_yaw` 与旧评价器、折叠runner和两份折叠manifest均不改；本版本是单独登记的成功分类层。

- **A / L1过折**：flat、left、width=0.20m、commanded overhang=0.02m、7动作、0次recovery。最终形状允许既有拱形和偏置覆盖，但必须满足过边自由边和持续保持要求。
- **B / nominal对折**：perturbed或crumpled、width=0.20m、overhang=0、5次recovery动作+7次折叠动作，总12动作、1次recovery。left/right使用镜像对称的同一评价阈值；本文件不授权将right替换冻结left，也不允许根据同一seed结果临时选边。
- 两个任务分别汇报，L2/L3作为任务B的不同初态族另列；single/arc4共用全部判据。不得把多任务平均解释为受控难度曲线或H=4收益。
- 这里冻结的是**仿真几何代理判据**，不是平整熨烫质量、真实夹持、自交/穿插或三角形面积重叠认证。允许拱高约6cm的既有任务形态，不能把“通过”改写成“平整贴合”。若要要求平整或无自交，须另建任务/评价版本。

## 2. 几何条件：每一项同时满足

每帧用441个固定物料索引计算；初始参考L1取折前平铺，B取recovery后、fold前的平铺。B另保留原扰动初态用于追溯，不能用原折条定义最终分半。折向、yaw、pick、地面高度由运行前/折前记录固定，禁止按最终形状重新拟合以消除误差。

| 指标 | A：L1过折 | B：nominal | 单位/意义 |
|---|---:|---:|---|
| moving材料越过折线比例 | ≥0.95 | ≥0.95 | 中线粒子排除，1µm几何容差；不能只把一小角折过线 |
| 粒子占据IoU | ≥0.30 | ≥0.50 | 沿用1cm栅格+一次膨胀的旧实现；不是面积IoU |
| 对称XY最近邻对齐均值 | ≤0.020 | ≤0.015 | m；与IoU共同限制覆盖 |
| 移动材料到nominal镜像目标的XY均值误差 | ≤0.060 | ≤0.030 | m；A仍用nominal参考以保持旧指标可比，另用自由边指标识别过折 |
| 静止半片相对折前的逐点3D位移均值 | ≤0.025 | ≤0.025 | m；限制整件搬移，非最终形状配准后的残差 |
| 沿折向全布跨度 | [0.16,0.28] | [0.16,0.28] | m；排除摊平/严重收缩 |
| 垂直折向的全布跨度 | [0.36,0.44] | [0.36,0.44] | m；保留约40cm原边长 |
| 离地高度p95 | ≤0.09 | ≤0.09 | m；容纳既有拱形但排除高悬 |
| 所有顶点离地高度范围 | [-0.002,0.12] | [-0.002,0.12] | m；允许2mm数值/接触容差，不认证无穿透 |
| 移动自由边行均值相对当前静止远边的有符号越边量 | [0.02,0.06] | [-0.03,0.03] | m；按物料边行而非极值单点计算，right先镜像方向 |
| 移动自由边离地高度p90 | ≤0.015 | 不加此条件 | m；A的自由边落桌形态代理，不能当作接触传感证明 |

区间边界包含端点。旧crossed指标仍输出，分类使用排除中线并容忍1µm的 `crossed_fraction_tolerant`；该差异属于本次明确登记的版本变更。其余旧指标算法保持不变。

## 3. 释放、时刻与稳定性

**唯一时钟**：最后一次公开OPEN动作完成的物理步为 `t=0`，dt=1/60s，立即采样step0。之后不新增公开动作、不重抓取、不重新移动布料、不reset；只维持既定机器人静止目标、推进物理并采样。记录0..330每个物理步，共331帧。

**正式几何/稳定窗口**：step210..330，即OPEN完成后 **3.5–5.5s**，121帧。几何表所有条件必须在121帧全部成立；不能只选最终一帧，也不能按结果延长等待。t=3.5s对应既有30 tick+180 settle的常用终态，增加固定2s作为独立保持窗口。旧L3采用不同settle步数的历史结果不伪装为同一时钟。

**释放要求**：从step0至330持续观测 `holding=false`、所有三个 `attachment_enabled=false`、实际观测的 `gripper_open=true`。不得用预期命令值代替状态；附件对象可保留，但不得启用。冻结前held gate沿用：位置A<10mm/B<30mm，臂速<0.1rad/s，姿态到达，最大锚点间隙≤10mm；errors为空且动作/恢复数匹配。

**稳定要求**（整个2s窗口，不做刚体配准）：

| 指标 | 上限 |
|---|---:|
| 质心相对窗口首帧的最大位移 | 1mm |
| 各帧逐点位移p95的最大值 | 3mm |
| 任一帧任一顶点位移 | 10mm |
| 相邻物理帧逐点速度p95的最大值 | 10mm/s |
| 任一顶点相邻帧速度 | 50mm/s |

速度由同物料点相邻帧3D差分/dt计算，不能只看质心速度；需同时通过位移与速度以排除持续滑动和来回振荡。

**明确边界**：现有7/12动作协议没有额外退让动作。本判据只声称“释放后、机器人保持既定姿态时的5.5秒观察”，不声称机械臂退让后保持、机器人无支撑接触或长期稳定。若后续要求退让，必须同时重新登记动作预算和采样时钟，不能藏在Backend里。本次也不更改粒子/手指碰撞或接触正控含义。
