# 4202 L2 初态敏感性离线定位（old rc8 vs new rc8b，无新增仿真）

**结论：** 新旧 4202 的差异在载入时是**整体位姿差**（质心 2.796 mm、旋转 −0.256°，对齐后残差 P95 0.043 mm），recovery 后仍是刚体平移（2.022 mm、−0.042°，残差 P95 **0.001 mm**），pre-release 时内部折形差异仍很小（质心 1.718 mm、−0.371°，残差 P95 0.649 mm / max 0.796 mm）。**差异在释放后才放大**：新初态的布料从释放后约 0.5 s 起持续以 ~4 mm/s 滑移，旧初态衰减到 ~0.5–0.8 mm/s；首个几何失败在 release 后 **4.15 s**（formal 窗口开始 3.5 s，即窗口内 0.65 s），stationary half 漂移 29.9 mm。失败不是“初态形状大幅不同”，而是**小位姿差 + 释放后未锁住**。

## 1. 数据与方法

- old：rc8 4202 single `…20261104-234933-939207`（旧初态，生成 0.0；accepted 0.2642/0.3792 mm）。
- new：rc8b 4202 single `…20261105-025057-237749`（新初态，生成 1.0；rejected 7.4809/11.5382 mm）。
- 只读两目录的 `pfs1_stages`、`pre_release_hold.npz`、`pfs1_release_steps.npz`、`success_trace.npz`、`result.json`、`a5-verdict.json`；未启动仿真。
- 对齐方法：2D 刚体拟合（旋转+平移，无缩放）后计算顶点残差；z 用原始高度。

## 2. 阶段对比（new vs old）

| 阶段 | 质心差 (mm) | 旋转差 (°) | 对齐后残差 P95 / max (mm) | 结论 |
|---|---:|---:|---|---|
| 初态 final | 2.796 | −0.256 | 0.043 / 0.147 | 几乎纯位姿差 |
| 载入后 `initial_loaded` | 2.795 | −0.257 | 0.046 / 0.126 | 载入未放大 |
| recovery 后 `after_recovery` | 2.022 | −0.042 | **0.001 / 0.001** | 内部形状几乎相同，纯平移 |
| 抓取前（同 after_recovery） | 2.022 | −0.042 | 0.001 / 0.001 | 无独立抓取前帧 |
| pre-release | 1.718 | −0.371 | 0.649 / 0.796 | 折形仍接近 |
| release boundary | 1.688 | −0.367 | 0.604 / 0.708 | 与 pre-release 相同量级 |

**回答步骤 1/2：** 差异在载入时已存在且是整体位姿；recovery 后内部形状几乎逐点相同（1 µm 级），pre-release 的内部折形差 <0.8 mm；**没有在载入→recovery→pre-release 之间放大**。放大发生在释放之后。

## 3. Recovery 运动是否已稳定？（未知，不能由 9.2 µm 推断）

- 数据中没有 recovery 的逐物理步轨迹；`after_recovery` 只有单帧。`fd_velocities` 为空，无法做位置差分速度。
- 该帧的 `readback_velocities`（**unvalidated**）均值：old 0.0105 mm/s、new 0.0111 mm/s；最大 0.039 / 0.042 mm/s。原始读回不能当作物理速度，也不能证明残余运动/接触/应力为零。
- 9.2 µm 的 `rigid_residual_vs_flat` 只是几何展平误差，**不证明速度、接触或内部应力已消失**；这些量在本数据中为**未知**。
- 可观测的替代指标：recovery 总时长 16.38 / 16.47 s；质心总位移 79.1 / 79.9 mm（平均 4.83 / 4.85 mm/s，包含全部 recovery 动作，不是末段速度）。pre-release hold 的漂移 old/new 相似（质心 3.33 / 3.67 mm，最大顶点 23.9 / 24.5 mm，3 s），不能区分两者。

## 4. 专家重算的 pick / yaw / 目标

- `fold_yaw`：old 6.181°、new 6.223°，差 **0.042°**。
- `pick_index` 两者均为 230；recovery 动作目标差 **2.74 mm**（x −0.53、y +2.74），fold 目标差 **1.87–2.16 mm**，release retreat 差 1.88 mm；yaw 差 0.042°。
- 目标差与 2 mm 的刚体平移一致，不是“专家路径大幅不同”。pre-release 的 1.7 mm / 0.37° 也在此量级。

## 5. 释放后分段与首次失败

| 时间段 | 旧质心速度 | 新质心速度 | 旧/新累计位移 |
|---|---:|---:|---:|
| 0–0.5 s | 11.56 mm/s | 4.08 mm/s | 4.96 / 1.37 mm |
| 0.5–1.0 s | 1.47 | **3.84** | 0.67 / 1.52 |
| 1.0–1.5 s | 0.67 | **3.96** | 0.25 / 1.73 |
| 1.5–2.0 s | 0.58 | **4.08** | 0.18 / 1.80 |
| 3.5–4.0 s（窗口初） | 0.58 | **4.24** | 0.05 / 1.90 |
| 4.0–4.5 s（首次失败附近） | 0.58 | **3.80** | 0.10 / 1.75 |

- 新初态在释放后不再衰减，持续 ~4 mm/s；旧初态 0.5 s 后降到 ~0.5–0.8 mm/s。
- **首个几何失败：success_trace step 249 = release 后 4.15 s = formal 窗口开始后 0.65 s**；窗口 210–248 通过，249–330 失败（82 帧）。old 无失败帧。
- 因此失败**不是释放前已形成的几何差**，而是释放后新初态的折叠件没有锁住、持续滑移；pre-release hold 两版漂移相似，不能把差异归到 hold 阶段。

## 6. 解释边界

- “3 mm 初态差 → 30 mm 滑移”是**相关观察**，不是因果；本数据不能分离残余速度、折层接触、内部应力或释放瞬间的接触状态。
- 新初态的内部折形在 pre-release 仍接近旧初态（残差 <0.8 mm），但释放后进入持续滑移；触发点更可能在释放瞬间的接触/速度/姿态组合，而不是折形本身。
- 旧初态与新初态的差异主要是**整体位姿**（2–3 mm、0.26°）；recovery 后是 2.0 mm 的纯平移。

## 7. 下一步：一个针对性单次对照（建议，未运行）

证据不足以归因到“recovery 残余运动”（未记录）或“专家路径大幅不同”（仅 2 mm 级）。因此不建议改 hold 时长或盲扫摩擦；建议做**位姿匹配对照**：

> 把旧初态的 settled 几何施加“旧→新”的刚体变换（2.796 mm、−0.256°），得到“旧内部状态 + 新位姿”的初态；在同一 rc8b rollout 配置下跑一次 4202 single。

- 若它也像新初态一样滑移 → 失败由**位姿/释放放置**触发，而不是 1.0 生成带来的隐藏状态；
- 若它保持旧初态行为 → 新初态在 1.0 下生成的隐藏状态（接触/应力/速度）才是关键，再针对释放瞬间做对照。

该对照需要新建一个诊断初态目录与单例账本（不改七例矩阵、不改阈值、不重跑七例）；详细预登记见 [SINGLE_COMPARISON_PLAN.md](SINGLE_COMPARISON_PLAN.md)。
