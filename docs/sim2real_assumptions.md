# 真机迁移的最小假设

## 当前范围
本 demo 先完成仿真实验，尚未连接或验证真实机器人。
以下是后续接口设计的暂定假设，需与实验室确认。

## 目标设备与任务
- 单机械臂，机器人型号待定。
- 平行夹爪，型号及控制接口待定。
- 顶视 RGB-D 相机，型号待定。
- 桌面上的方巾或毛巾。
- 首先从平整或轻度扰动状态完成一次对折。

## 观测接口
- 衣物关键点及其有效性、置信度。
- 末端位姿和夹爪状态。
- 时间戳、任务阶段。
- 相机内外参、坐标系和长度单位需明确记录。

仿真阶段允许使用真实关键点，但必须标注为 oracle 输入。
真机阶段需要 RGB-D 关键点估计和坐标标定。

## 动作接口
- 策略输出笛卡尔 waypoint 和夹爪指令。
- 夹爪指令：open / close / hold。
- 策略不直接输出关节角或力矩。
- Backend 负责坐标转换、轨迹执行和执行状态反馈。
- H=4 策略预留仅执行前 1、2 或 4 步的参数。

## 后续验证
- 确认机械臂、夹爪、相机及控制接口。
- 完成相机与机器人坐标标定。
- 在真实执行前验证工作空间、速度限制和停止机制。
- 采集真实示教并评估是否需要微调。
- 不预设仿真策略可以直接迁移成功。
